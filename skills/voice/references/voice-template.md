# voice.md template

Fill each section from the samples and the interview. Delete a section
that has nothing person-specific in it. Every rule must be checkable: a
reviewer can point at a sentence that breaks it.

```markdown
# Voice: <name>

Applies to everything written by or for <name>: <venues>.

## Voice

- <rule, e.g. "Lead with the point. Context after, if at all.">
- <rule, e.g. "One claim per sentence.">
- <how to state an unknown, in their words>
- <spelling variant>
- <punctuation rules: em dashes, exclamation marks, emoji>
- Banned: <words and phrases they never use>

## Venues

### <venue, e.g. Slack>

- <venue-specific rule, e.g. "lowercase, no greeting, no sign-off">

### <venue, e.g. commit messages>

- <format, e.g. "type(scope): description, imperative, lowercase">

## Long-form traits

From <name>'s writing, <date range>. Each trait with a verbatim quote.

1. <trait>: "<quote>" (<source>)
2. <trait>: "<quote>" (<source>)

## Tensions

- <where two venues pull different ways, and which wins where>

## Open questions

- <anything the test drafts did not settle; tentative or self-reported
  traits>
```
